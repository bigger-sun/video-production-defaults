# 短视频模板库

当前模板分为两类：

全局版式规范：[layout-constants.md](layout-constants.md)

## 01｜信息型短视频

适合清单、榜单、数据、截图、工具推荐和 Logo 矩阵。

- [list-cards｜清单卡片](01-信息型短视频/list-cards/README.md)：3–5 张卡片，适合工具清单、技巧、功能列表
- [role-showcase｜角色对比](01-信息型短视频/role-showcase/template.jsx)：角色或行业对比
- [screenshot-list｜截图亮点](01-信息型短视频/screenshot-list/template.jsx)：软件截图 + 功能亮点
- [quick-python｜三卡速览](01-信息型短视频/quick-python/template.py)：3 张紧凑卡片，适合榜单、排名、警告
- [multi-image-rotation｜多图轮播](01-信息型短视频/multi-image-rotation/render.py)：多图轮播 + 标题 + 重点列表
- [six-card-list｜六卡场景清单](01-信息型短视频/six-card-list/README.md)：钩子 + N 张场景卡片
- [title-card-image｜标题主图](01-信息型短视频/title-card-image/render.py)：多行标题 + 单张主图
- [数据爆点·证据轮播](01-信息型短视频/07-数据爆点-证据轮播/template.md)：顶部结论 + 中央截图/视频/动画证据 + 下方完整解读
- [黑底榜单·数据长表](01-信息型短视频/08-黑底榜单-数据长表/template.md)：黑底高对比排名表，支持滚动、翻页与数据来源
- [分类工具矩阵·Logo 墙](01-信息型短视频/09-分类工具矩阵-Logo墙/template.md)：蓝紫渐变 + 黄色推荐条 + 分类 Logo 矩阵
