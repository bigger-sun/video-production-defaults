# Six Card List Template

面向“六个问题、六个步骤、六项能力”等高密度信息短视频。默认输出为 1080×1920、30 fps，使用 Python + Pillow + FFmpeg 渲染。

## 默认结构

- 首屏 4 秒：标题 + N 条问题导航。
- 正文：每张卡片 3 秒，标题固定在卡片外上方。
- 卡片内部：标签、核心结论、紧凑解释要点、可选“记住”句。
- 无独立收尾页：最后一张卡说完立即结束。
- 六张卡默认总时长：`4 + 6 × 3 = 22 秒`。

## 已固化的版式规则

1. 首屏列表每条都有独立上下内边距，条目间保留 24 px 间距。
2. 问题较长时按实际宽度换行，换行前后字符必须完全一致。
3. 正文标题放在卡片外上方，卡片只承载解释内容。
4. 三条解释连续紧凑排列，不把剩余高度平均摊成大空隙。
5. 卡片高度按内容自动计算；内容少则卡片缩短，多行内容则自然扩展。
6. 卡片触及进度条安全区时直接报错，要求缩短文案或拆分场景，不通过缩小正文解决。
7. `DeepSeek Harness` 等不可拆短语可通过手工 `question_lines` 控制换行。

## 推荐数据格式

```python
ITEMS = [
    {
        "question": "1、Harness 是什么？",
        # 可选。填写时，拼接结果必须与 question 一字不差。
        "question_lines": ["1、Harness 是什么？"],
        "tag": "运行时框架",
        "conclusion": ["让大模型真正干活的运行时框架"],
        "bullets": [
            ["管理感知→规划→行动→观察循环"],
            ["提供工具、记忆、会话和安全能力"],
            ["把模型输出变成可执行动作"],
        ],
        "takeaway": ["它是模型的手、流程和安全带"],
    },
]
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---:|---|
| `question` | 是 | 首屏和正文卡片外显示的标题原文 |
| `question_lines` | 否 | 手工换行；所有行拼接后必须等于 `question` |
| `tag` | 否 | 卡片内的小标签 |
| `conclusion` | 是 | 核心结论，可用多行列表 |
| `bullets` | 否 | 解释要点；每个要点也可以是多行列表 |
| `takeaway` | 否 | “记住”区域，可用多行列表 |

## 兼容旧格式

旧四元组仍可运行：

```python
ITEMS = [
    ("口播剪辑", "短视频", "录完口播，一句话剪完", "自动转写并删除停顿"),
]
```

映射关系为：名称→问题标题、标签→标签、金句→核心结论、描述→一条解释。旧格式没有“记住”区域，因此卡片会自动更短。

## 图片模式

- 默认 `USE_IMAGES=False`，使用结构化文字卡。
- 改为 `True` 且存在 `WORK_DIR/img_{idx}.jpg` 时，在卡片内加入 320 px 高的图区。
- 图片不存在时自动回退为纯文字卡。
- 图片模式同样使用标题外置、动态卡高和安全区检查。


## 渲染

```bash
cd /Users/biggersun/.workbuddy/skills/video-production-defaults/templates/01-信息型短视频/six-card-list

```

默认输出：

- `/tmp/six-card-list/video.mp4`：无音轨视频。
- `/tmp/six-card-list/bgm.m4a`：按成片时长截取的 BGM。
- `/tmp/six-card-list/final.mp4`：最终混音成片。

封面默认不生成。只有用户明确要求封面时，才单独运行 `cover.py` 或使用图像生成能力。

## 交付检查

- 首屏列表是否有清楚的条目间距。
- 所有标题是否位于卡片外上方。
- 手工换行前后是否保持原文和标点完全一致。
- 正文解释是否紧凑、没有大面积无意义间隔。
- 卡片是否根据内容自动收缩，且不触碰进度条。
- 每张卡是否准确显示 3 秒。
- 第一处可见内容是否位于顶部 200 px 安全线以下。
- 最终 MP4 是否为 1080×1920、30 fps，并包含可听且不削波的音轨。
- BGM 是否经过音量检测；默认 `BGM_VOLUME=0.48`，仍应以实测结果为准。
